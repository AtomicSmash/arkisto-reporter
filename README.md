# Arkisto Reporter

Minimal WordPress plugin that registers a site with Arkisto and reports installed plugins daily.

## Setup

1. Copy `wordpress/arkisto-reporter` into `wp-content/plugins/` on the WordPress site.
2. Activate **Arkisto Reporter**.
3. Open **Settings → Arkisto Reporter**.
4. Paste the API base URL and registration token from Arkisto → Sites.
5. Click **Register site**, then **Send heartbeat now**.
